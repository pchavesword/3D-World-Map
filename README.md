# Sword Health — interactive testimonial globe

Vite + React + TypeScript, three.js via react-three-fiber, GSAP.

```bash
npm install
npm run dev
```

## Globe textures

`public/textures/` is generated by `npm run textures` from two public-domain sources:

- NASA Visible Earth topography (SRTM/RAMP2), 2048×1024 — `scripts/source/earth-topology.png`
- Natural Earth 1:10m land polygons (via the `world-atlas` package)

The script writes height, normal and albedo maps at 4K (desktop) and 2K (mobile).
